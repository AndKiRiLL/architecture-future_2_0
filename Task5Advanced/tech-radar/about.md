Радар отражает решения на старте трёхлетней трансформации, а не подтверждает,
что новые технологии уже внедрены в компании.

## Кольца

- **Adopt** — сохранять и использовать существующий проверенный стек.
- **Trial** — ограниченный пилот перед промышленным расширением.
- **Assess** — оценить применимость, ограничения и готовность команды.
- **Hold** — не использовать в новых решениях; действующие системы выводить поэтапно.

Data Mesh, Event-Driven Architecture и Self-service BI — архитектурные подходы.
В каждой карточке указаны причина статуса, следующий шаг и ответственный.

## Запуск приложения

Нужен Node.js 22. Из корня репозитория выполните:

```bash
cd Task5Advanced/tech-radar
npm install
npm run serve
```

Откройте http://localhost:3000/. Для остановки нажмите Ctrl+C.
Если package-lock.json уже есть в репозитории, вместо npm install можно использовать npm ci.

Для получения статического сайта выполните:

```bash
npm run build
```

Результат находится в build/. AOE самостоятельно создаёт служебную папку .techradar/.
Для установки зависимостей и сборки нужен доступ к npm и Google Fonts.
В Git добавляются исходники и package-lock.json; node_modules/, .techradar/ и build/ исключены через .gitignore.

## Обновление радара

Редактируйте config.json и карточки radar/2026-11-11/, затем перезапустите приложение
или повторите сборку. Пересматривайте статусы после пилотов и не реже раза в полгода.
TCO-анализ и роадмап находятся рядом с приложением в Task5Advanced.
